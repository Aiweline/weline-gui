# 安全模型

## 默认边界

- Headless 代理默认只监听 `127.0.0.1:17640`。
- 监听非回环地址时，缺少证书或私钥会直接拒绝启动。
- 除健康检查外，API 使用逐字节恒定时间比较的 Bearer Token 鉴权。
- 安装时生成随机令牌；使用 `weline-agent token --rotate` 可立即轮换。
- 配置 API 永远不返回令牌。

## 命令控制台

控制台不是通用终端。输入先经过词法拆分，只接受 `php bin/w …` 或 `bin/w …`；`; & | \` $ < >`、换行、空字节等 Shell 语法会被拒绝。进程通过参数数组直接启动，并设置执行目录、超时和空标准输入，不调用 `/bin/sh`、PowerShell 或 `cmd.exe`。

这仍然是高权限管理能力：能运行的框架命令可能修改框架数据。因此令牌应按管理员凭据管理，代理不能直接暴露在不可信网络。

## 远程访问

推荐顺序：

1. 回环监听 + 现有 HTTPS 反向代理/VPN；
2. 代理自身 TLS + 防火墙源地址限制；
3. 临时使用 SSH 端口转发。

不要在公网使用明文 HTTP。CORS 仅允许配置的来源，同源 Web UI不需要额外放宽。

## 内嵌管理面板

iframe 使用 sandbox 权限，并保留“独立窗口打开”降级入口。若管理站点通过 `X-Frame-Options` 或 CSP `frame-ancestors` 禁止嵌入，客户端不会绕过该策略。登录、Cookie 与站点权限仍由管理面板自身负责。

## 证书观察

证书监控需要读取失效、过期或域名不匹配证书的元数据，因此探测连接只用于观察，不把该连接当作受信任的业务请求。界面的有效状态检查时间范围与 SAN/CN 主机名匹配；主题、签发者、序列号和 SHA-256 指纹来自实际握手证书。当前版本不单独宣称系统 CA 信任链已验证，用户仍应通过浏览器、反向代理或证书运维工具完成信任链校验。

## 更新

GitHub API 只用于判断最新正式版本和显示发布说明，不会执行 Release 中任意文件。发布包必须在 CI 中生成并签名；签名私钥只放在 GitHub Actions Secrets，不进入仓库。
